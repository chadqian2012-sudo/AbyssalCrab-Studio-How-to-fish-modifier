## 行为 | Behavior

- 显式恢复上次退出前的有效参数、倍率和持续功能开关；启动保持关闭，生成、传送、加钱等一次性操作不重放。普通预设仍仅恢复参数。
- 恢复清锁抛异常或切换世界后，辅助瞄准仍可配置，旧回包不能污染当前连接。
- 紧急停用取消在途恢复，并在等待回包前撤销重连恢复意图；重复停用、桥接握手和断线回包均使用原有连接边界。
- 手记游戏退出和中断恢复遇到文件占用时保留结束时刻和原因，重试不能延长旧局或把新鱼获归入旧局。
- 同步参数草稿/最后有效值、目录选择、娱乐控制、位置/成员及已保存配置的一致性修复。
- 同步独立队友筛选、魔法子弹范围圈、大陀螺姿态与雷达/坡面处理的相关源码。真实效果仍按验收记录逐项确认。

Explicit session restoration loads valid saved parameters, multipliers and sustained switches without replaying one-shot actions. Restoration errors and world changes no longer leave aim controls detached. Emergency stop cancels pending restoration and revokes reconnect intent before awaiting confirmation. Journal retries retain the original completion timestamp and session ownership. Intervening numeric-input, catalog, entertainment and position/member fixes are included, alongside supporting runtime changes.
